# Changelog

## Browser — v2.0.0
- Custom 1–200 column and row board sizes.
- Binary or multi-colour mapping with up to 20 editable palette colours.
- Automatic colour palette generation in the browser.
- Per-colour peg inventory and CSV/JSON exports.

## Python — v2.0.0
- Custom board dimensions and 1–20 colour mapping.
- Colour picker, editable paint index and CSV/JSON exports.
- Preserves original binary output as the default.

## Browser — v1.9.2
- Added GitHub update/download metadata for Tampermonkey auto-update checks.

## Browser — v1.9.1
- Renamed the application **Pegboard Mapper — by Pegzel**.
- Retained explicit Tampermonkey menu-based launch, avoiding automatic website takeovers.
- Channel-aware binary conversion, preview edits and TXT/PNG exports.

## Python desktop — initial consolidated publication
- Published one Tkinter-based desktop script instead of maintaining separate Tkinter, Streamlit and Pygame programs.
- Added source channel selector (luminance, R, G, B, max RGB).
- Added pen and eraser overrides on the binary peg grid.
- Debounced window resize rendering and reset manual edits when opening a new source image.

## Browser — v1.9.0
- First GitHub publication of the userscript.
